SleepGuard

蓋を閉じてもMacを寝かせない。メニューバーから1クリック。

外付けディスプレイに繋いだまま蓋を閉じたい、ビルドやダウンロードを回したまま席を立ちたい—— そういうときに pmset -a disablesleep をターミナルで叩く代わりに、メニューバーのアイコンを押すだけで切り替えられます。 今どっちの状態なのかがアイコンで一目で分かります。

SleepGuard 1.0 をダウンロード macOS 13 以降 / Intel・Apple Silicon 両対応 / 約 320KB

ソースコード: github.com/Hiroki-Soeno/sleepguard

アイコンの見方

同じ月マークに、斜線が入っているかどうかだけで区別します。

メニューバーの表示状態
🌙 月だけ（白黒） 通常。蓋を閉じるとスリープします
🌙 オレンジの月＋斜線 スリープ無効中。蓋を閉じても起きたままです
🌙 赤の月＋斜線 スリープ無効中 かつバッテリー駆動。電池が減り続けています

左クリックで切り替え、右クリックでメニュー（状態の確認・ログイン時に起動・終了）。

インストール

A. ダウンロードして使う

Appleの開発者署名を付けていないので、初回だけ macOS の警告を通す操作が要ります（2回目以降は普通に開きます）。

  1. 上のボタンから zip をダウンロードして展開し、SleepGuard.app を 「アプリケーション」フォルダに入れる
  2. ダブルクリックする → 「Appleが悪質なソフトウェアでないことを確認できません」と出てブロックされる。「完了」を押す
  3. システム設定 →「プライバシーとセキュリティ」を開き、一番下までスクロール → 「"SleepGuard" は…ブロックされました」の行にある 「このまま開く」 をクリック（管理者パスワードを聞かれます）
  4. もう一度 SleepGuard.app をダブルクリック → 確認ダイアログで 「開く」

※ 昔の「Control+クリック →『開く』」の抜け道は macOS 15 Sequoia で廃止されています。macOS 26 でも使えません。

B. 自分でビルドする（警告が一切出ません）

macOS の警告は「ダウンロードしたファイル」に付く印（com.apple.quarantine）が原因なので、 手元でビルドしたものには そもそも警告が出ません。 Xcode Command Line Tools（swiftc）が入っていればこちらが早いです。 

git clone https://github.com/Hiroki-Soeno/sleepguard.git
cd sleepguard
./build.sh --install

ビルドして「アプリケーション」に入れ、そのまま起動するところまでやります。

初回起動時にひとつだけ

スリープ設定の変更には管理者権限が要るため、放っておくと切り替えるたびに毎回パスワードを聞かれます。 初回起動時に「パスワード不要にしますか？」と聞いてくるので、1回だけパスワードを入れてください。以降はクリックだけで切り替わります。

中身は /etc/sudoers.d/sleepguard に、次の2つのコマンドだけをパスワードなしで許可する行を書いているだけです。 それ以外のコマンド（sudo ls など）は今までどおりパスワードを要求します。 

pmset -a disablesleep 1
pmset -a disablesleep 0

あとから取り消したいときは、リポジトリの scripts/uninstall-sudoers.sh を実行してください。

知っておいてほしいこと

電源に繋いでいなくてもスリープしなくなります。 バッテリー駆動のまま蓋を閉じると電池が減り続け、カバンの中で発熱します。 その状態ではアイコンが赤になりますが、自動では元に戻しません。

この設定は再起動しても残ります。 アプリを終了しても設定自体は生きているので、戻すときはアイコンをもう一度クリックしてください。

今の状態はターミナルからも確認できます。 

ioreg -n IOPMrootDomain -r -d 1 | grep SleepDisabled

アンインストール

  1. メニューバーのアイコンが斜線なしの状態になっていることを確認する（スリープ設定を元に戻す）
  2. 右クリック →「終了」
  3. /Applications/SleepGuard.app をゴミ箱へ
  4. パスワード不要の設定も消すなら sudo rm /etc/sudoers.d/sleepguard
